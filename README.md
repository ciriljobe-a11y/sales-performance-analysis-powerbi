# Sales Performance Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Sales Performance Analysis Dashboard developed using Microsoft Power BI. It focuses on analyzing revenue performance, identifying growth trends, comparing regional sales, and monitoring revenue targets.

The dashboard provides business-oriented insights through visualizations, KPIs, and time-based analysis.

## Dashboard Features

- **Revenue Analysis:** Track total revenue and year-to-date (YTD) revenue.
- **Monthly Trends:** Analyze revenue performance across months.
- **Year-over-Year Comparison:** Compare current-year revenue against previous-year revenue.
- **Revenue Growth:** Monitor percentage growth over time.
- **Regional Performance:** Evaluate revenue contributions across different regions.
- **Target Analysis:** Compare actual revenue against revenue targets.
- **Variance Analysis:** Identify revenue differences and percentage variance against targets.
- **Interactive Filters:** Explore performance using year and month filters.

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- Business Intelligence

## Key Business Metrics

| Metric | Purpose |
|---|---|
| Total Revenue | Measures overall sales revenue |
| Revenue YTD | Tracks cumulative revenue |
| Previous Year Revenue | Enables historical comparison |
| Revenue Growth % | Measures revenue growth |
| Revenue Target | Tracks planned revenue |
| Revenue Variance | Measures target achievement differences |
| Regional Revenue Share | Evaluates regional contributions |
